## Homebrew Water Chemistry Profile Planner

Helps homebrewers adjust source water mineral content to match five classic beer style targets (Pilsner, Pale Ale, IPA, Stout, Hefeweizen). Enter your source water ions (Ca, Mg, Na, Cl, SO₄, HCO₃ in mg/L), specify batch volume, then dial in gram amounts of five common mineral additions (Gypsum, CaCl₂, Epsom Salt, Baking Soda, NaCl). The final profile updates live with in-range/low/high indicators per ion, plus the Cl⁻/SO₄²⁻ balance ratio.

**Tech:** Vanilla JS, Tailwind CSS CDN. No external dependencies.  
**Usage:** Enter source water values, select a style, adjust mineral additions until all ions show green.
